## 🎯 Quick Start (5 Minutes)

### Step 1: Read README.md
```bash
cat README.md
```

### Step 2: Copy Files
```bash
cp EnhancedWalletManager.ts src/lib/wallet/
cp useEnhancedWallet.ts src/hooks/
cp EnhancedWalletUI.tsx src/components/
cp MissionAndNFTSmartContracts.ts src/lib/contracts/
```

### Step 3: Install Dependencies
```bash
npm install @web3auth/modal @web3auth/base ethers viem pinata lucide-react
```

### Step 4: Add Environment Variables
```env
VITE_WEB3AUTH_CLIENT_ID=your_id
VITE_PINATA_JWT=your_jwt
VITE_MISSION_TRACKER_ADDRESS=0x...
VITE_NFT_MANAGER_ADDRESS=0x...
VITE_BADGE_SYSTEM_ADDRESS=0x...
```

### Step 5: Use in App
```tsx
import { EnhancedWalletUI } from '@/components/EnhancedWalletUI';

<EnhancedWalletUI 
  web3AuthClientId={import.meta.env.VITE_WEB3AUTH_CLIENT_ID}
  onMintSuccess={(txHash) => console.log('Minted:', txHash)}
  onMissionComplete={(id, addr) => console.log('Completed:', id)}
/>
```
