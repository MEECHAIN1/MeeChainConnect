# MeeChain Web3 Integration Package

## 📦 What's Inside

Complete, production-ready integration for:
- **Web3Auth** - Social login & key management
- **Account Abstraction (EIP-4337)** - Smart wallets with gasless support
- **NFT System** - Minting, evolution, and management
- **Mission System** - Quest tracking and rewards
- **Recovery** - Multi-factor wallet recovery
- **IPFS** - Decentralized metadata storage

## 🚀 Quick Start (5 Minutes)

### 1. Install Files
```bash
# Copy all .ts, .tsx, .md files to your project
cp EnhancedWalletManager.ts src/lib/wallet/
cp useEnhancedWallet.ts src/hooks/
cp EnhancedWalletUI.tsx src/components/
cp MissionAndNFTSmartContracts.ts src/lib/contracts/
```

### 2. Install Dependencies
```bash
npm install @web3auth/modal @web3auth/base ethers viem pinata lucide-react
```

### 3. Configure Environment
```env
VITE_WEB3AUTH_CLIENT_ID=your_id
VITE_PINATA_JWT=your_jwt
VITE_MISSION_TRACKER_ADDRESS=0x...
VITE_NFT_MANAGER_ADDRESS=0x...
VITE_BADGE_SYSTEM_ADDRESS=0x...
```

### 4. Add to Your App
```tsx
import { EnhancedWalletUI } from '@/components/EnhancedWalletUI';

export function App() {
  return (
    <EnhancedWalletUI 
      web3AuthClientId={import.meta.env.VITE_WEB3AUTH_CLIENT_ID}
      onMintSuccess={(txHash) => console.log('Minted:', txHash)}
      onMissionComplete={(id, addr) => console.log('Completed:', id)}
    />
  );
}
```

Done! 🎉

## ✨ Key Features

### 🔐 Smart Wallets
```typescript
// Create smart wallets with deterministic addresses
const wallet = await walletManager.createSmartWallet(
  'user@example.com',
  'Main Vault',
  'main'
);
// Address: 0x... (deterministic, deployed on first tx)
```

### ⚡ Gasless Transactions
```typescript
// 3 free transactions per day, sponsored
const txHash = await wallet.sendGaslessTransaction(
  '0xrecipient...',
  '0.1' // ETH
);
```

### 🔑 Multi-Factor Recovery
```typescript
// Email-based recovery
await wallet.setupSocialRecovery(id, 'backup@email.com');

// Biometric (Face/Fingerprint)
await wallet.setupBiometricRecovery(id);

// Guardian-based (trusted circle)
await wallet.setupGuardianRecovery(id, primary, backups);
```

### 🎮 Mission System
```typescript
// Complete missions, earn rewards
const result = await missionSystem.completeMissionFull(
  'mission_001',
  proof,
  userAddress,
  '100', // token reward
  1 // badge ID
);
```

### 🖼️ NFT Management
```typescript
// Mint NFTs
const { tokenId, txHash } = await nftManager.mintNFT(
  userAddress,
  'ipfs://QmXxx...' // metadata
);

// Evolve NFTs
await nftManager.evolveNFT(tokenId, 'ipfs://QmNew...');
```

## 🐛 Troubleshooting

### Web3Auth not loading?
```typescript
// Check:
1. Client ID correct in env
2. Allowed origins configured
3. @web3auth/modal CSS imported
4. Modal z-index set high enough
```

### Transactions failing?
```typescript
// Check:
1. Wallet has balance
2. Contract addresses correct
3. Network is correct
4. Gas limit sufficient
```

### IPFS timeout?
```typescript
// Solution: Use multiple gateways
const gateways = [
  'https://gateway.pinata.cloud/ipfs/',
  'https://cloudflare-ipfs.com/ipfs/',
  'https://ipfs.io/ipfs/',
];
```

See INTEGRATION_GUIDE.md for more troubleshooting.
